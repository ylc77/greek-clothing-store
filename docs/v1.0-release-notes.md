# v1.0.0 Release Notes

Release date: pending final Release PR  
Deployment status: code/template release; Production deployment requires a separate authorized rollout

## Highlights

- Greek/English clothing storefront, categories, product pages, contact and configurable bilingual retail legal pages.
- Chinese admin optimized for desktop, tablet and mobile core workflows.
- EU letter/numeric/shoe/ONE SIZE/custom sizing, supplier SKU and optional procurement/product-compliance fields.
- Authoritative Variant inventory in `MAIN_STORE`, fast stock lookup, receiving, adjustment, stocktake, return and owner-only Quick Sell.
- Transactional POS checkout/void, payments, daily report, receipts, barcode and label preparation.
- Transactional product create/edit and resumable CSV import Jobs with idempotency and recovery records.
- Per-customer developer credentials, role-based employee accounts and four-layer Feature Gates.
- Hardened public DTOs, RLS/grants, Storage image validation/lifecycle, shared AI/auth abuse protection and security headers.
- Skroutz XML generated from complete eligible products and authoritative available inventory.
- Database + Auth + Storage backup, verification and empty-target restore CLI.

## Database

- 21 ordered migrations beginning with `20260702000000_baseline_store_schema.sql`.
- New customers may use the generated `supabase/client-init.sql` once on an empty project.
- Existing customers must use `supabase link`, `db push --dry-run`, then `db push`; never run `client-init.sql` on an existing database.
