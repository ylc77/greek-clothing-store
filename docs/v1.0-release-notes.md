# v1.0.0 Release Notes

Release date: 2026-07-19

Deployment status: code/template released; isolated Preview and the Vercel/Supabase Production demo are technically verified

## Highlights

- Greek/English clothing storefront, categories, product pages, contact and configurable bilingual retail legal pages.
- Chinese admin optimized for desktop, tablet and mobile core workflows.
- EU letter/numeric/shoe/ONE SIZE/custom sizing, supplier SKU and optional procurement/product-compliance fields.
- Authoritative Variant inventory in `MAIN_STORE`, fast stock lookup, receiving, adjustment, stocktake, return and owner-only Quick Sell.
- Transactional POS checkout/void, payments, daily report, receipts, barcode and label preparation.
- Transactional product create/edit and resumable CSV import Jobs with idempotency and recovery records.
- Per-customer developer credentials, role-based employee accounts and four-layer Feature Gates.
- Hardened public DTOs, RLS/grants, Storage image validation/lifecycle, shared AI/auth abuse protection and security headers.
- Skroutz XML generated from complete eligible products and authoritative available inventory.
- Database + Auth + Storage backup, verification and empty-target restore CLI.

## Database

- 27 ordered migrations, including four verified legacy-history compatibility markers, legacy `image_urls` normalization, and the baseline beginning with `20260702000000_baseline_store_schema.sql`.
- New customers may use the generated `supabase/client-init.sql` once on an empty project.
- Existing customers must use `supabase link`, `db push --dry-run`, then `db push`; never run `client-init.sql` on an existing database.

## Release status

- Basic: `READY`.
- Standard: `CONDITIONAL` pending real scanner/label/receipt hardware acceptance.
- Advanced: `CONDITIONAL` pending the same hardware acceptance; software Skroutz and AI gates passed.

## Production verification

- The Production demo at <https://greek-clothing-store.vercel.app> passed migration, runtime health, reconciliation, strict Feed, browser accessibility, logging and Daily site monitor acceptance.
- Production uses a rotated per-customer developer credential and a dedicated server-only Supabase Secret key; the superseded default Secret key was revoked.
- The demo's Legal Settings are intentionally not published because no real merchant legal identity was provided. Complete and professionally review customer-specific legal content before commercial use.
- Standard and Advanced remain conditional on each customer's real scanner, label printer, paper and receipt printer acceptance.
