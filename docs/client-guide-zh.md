# 商家后台使用说明

## 登录后台

1. 浏览器打开 `https://你的域名.com/admin`
2. 输入管理密码（由技术人员提供）
3. 点击登录

## 修改店铺信息

进入「店铺设置」页面：

- **店铺名称**：显示在网站顶部、首页标题、页脚
- **Logo**：点击「上传」选图片，显示在网站左上角
- **首页大图**：显示在首页右侧，建议用横向图片
- **电话 / WhatsApp / Instagram**：填写后网站会显示对应联系按钮，不填就不显示
- **地址 / Google Maps**：填写后首页会显示店铺位置
- **营业时间**：每行一条，例如 `Monday - Friday: 10:00 - 20:00`
- **简介**：三语简介会显示在首页和联系页
- **页脚文字**：不填会自动生成版权信息
- 修改完点「保存设置」

## 管理商品

### 新增商品

1. 进入「新增/编辑」Tab
2. 填写 SKU（商品编号），选择分类后会自动生成建议，点「生成编号」即可
3. 选择一级分类，二级分类会自动联动
4. 填写价格
5. 填写中文、英文、希腊语商品名和描述
6. 点「自动翻译」可从中文自动翻译英文和希腊语
7. 在「尺码库存」区域添加尺码（点 XS/S/M/L 等按钮），填写每个尺码的库存数量
8. 在「图片与链接」区域上传商品主图和多图
9. 有真实 EAN 或制造商 MPN 时可选填，没有就留空
10. 点底部「新增商品」

### 编辑商品

1. 在商品列表找到该商品，点「编辑」
2. 修改后点「保存修改」

### 删除商品

在商品列表点「删除」→ 确认即可。

### 尺码库存说明

- 每个尺码可以单独设置库存数量
- 库存为 0 的尺码在前台会显示售罄（灰色不可点击）
- 保存时总库存会自动计算
- 如果商品原来只有总库存没有尺码库存，会提示您手动分配

## 管理分类

进入「分类管理」Tab：

- **一级分类**：网站导航和首页的分类入口
- **二级分类**：每个一级分类下的子类别，用于商品筛选
- 可以修改名称（中文/英文/希腊语）、排序、启用或停用
- 停用的分类不会在前台显示，但已有商品不受影响

## CSV 导入导出

### 导出商品

在商品列表页点「导出 CSV」，下载完整商品资料。该文件不是数据库灾难恢复备份，不包含全部订单、账号、设置和 Storage 文件。

### 导入商品

1. 进入「CSV 导入」Tab
2. 点「下载 CSV 模板」获取格式文件
3. 按模板填写商品信息
4. 上传后先完成服务端预检；文件结构或字段错误时不会写入数据
5. 选择 `create_only`（仅新增）、`update_existing`（仅更新）或明确确认的 `upsert`
6. 选择 `metadata_only`（不改库存）或 `set_inventory`（按填写数量设置库存）
7. 如需翻译，先检查最终翻译预览，再确认导入
8. 刷新或网络中断后恢复原导入 Job；可下载失败行并只重试失败行

## 商品图片

- **上传方式一**：编辑商品时直接在图片区域上传
- **上传方式二**：进入「批量图片上传」Tab，按文件名匹配上传
- 图片会自动压缩，建议用 JPG 或 PNG 格式
- 主图是商品封面，多图是详情页轮播图

## 常见问题

**Q: 为什么上传图片后前台不显示？**
A: 编辑商品时上传图片后，还需要点「保存修改」。新商品上传图片是在保存时自动上传的。

**Q: 尺码按钮为什么有的不能点击？**
A: 该尺码库存为 0，前台会自动显示售罄。在后台给该尺码填写库存即可。

**Q: 为什么营业时间显示英文？**
A: 营业时间是一个字段，英语界面显示英文，希腊语界面会自动翻译星期几。

**Q: 如何修改后台密码？**
A: 在 Vercel 环境变量中修改 `ADMIN_PASSWORD`，重新部署后生效。
