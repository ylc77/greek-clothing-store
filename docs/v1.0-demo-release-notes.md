# v1.0 Commercial Demo Release Notes

## Version Positioning

`v1.0` is the commercial demo version of the clothing store website and lightweight ERP/POS system.

This version is designed to show a small clothing shop owner how one system can manage:

- Online product display
- Product and image management
- Inventory control
- Barcode label workflow
- POS checkout
- Order history
- Skroutz Feed export

It is suitable for commercial demonstration, pilot testing, and client discussions.

## Features Not Recommended For Live Demo Writes

During a client demo, avoid real production writes unless using a dedicated test product:

- Real POS checkout
- POS order void on real customer orders
- Manual inventory adjustment on real stock
- CSV import into production
- Permanent product delete
- Bulk barcode generation on real products
- Bulk active/inactive changes
- Production environment variable changes

Recommended demo approach:

- Use storefront browsing freely.
- Use admin read-only views freely.
- Use POS dryRun for checkout demonstration.
- If a real checkout is necessary, use a test product and void it immediately.

## Deferred Features

These are intentionally not part of v1.0:

- myDATA integration
- Formal electronic invoice issuing
- Invoice provider integration
- ESC/POS printer integration
- Local print bridge
- Real label printer hardware validation
- Employee roles and permissions
- Complex refund
- Partial return
- Supplier purchasing
- Multi-store / multi-warehouse inventory
- Full accounting ERP

## Client-Friendly Summary

This version is a clothing store website plus lightweight back-office system.

It can show products online, manage inventory, print barcode labels, run POS checkout, track sales orders, and export a Skroutz Feed.

It is not yet a full tax invoice system. Official invoice and myDATA integration should be handled in a later phase after choosing a Greek invoice provider.
